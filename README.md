SkillUp — Job Search Platform

О проекте

SkillUp — это минимальная платформа для поиска работы, разрабатываемая в рамках учебного курса HCI (Human-Computer Interaction).

Цель проекта — создать простой и удобный интерфейс, который поможет пользователям искать вакансии и находить подходящие карьерные возможности.

Проект направлен на изучение принципов взаимодействия человека с компьютером (HCI), проектирования пользовательского интерфейса (UI) и улучшения пользовательского опыта (UX).
